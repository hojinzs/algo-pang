# 뉴트리션 팡 기획 문서

## 1. 목표

알고케어의 영양제와 디스펜서를 비주얼 모티브로 삼은 모바일 우선 3매치 게임을 만든다. 목표는 브랜드 전환보다 바이럴과 반복 플레이이며, 게임 후 공유 가능한 결과와 도감 수집 욕구를 핵심 루프로 둔다.

## 2. 핵심 콘셉트

- 게임명: 뉴트리션 팡
- 장르: 모바일 캐주얼 3매치 퍼즐
- 톤: 밝은 팝 캐주얼
- 비주얼: 실제 알고케어 영양제를 참고한 클린 제품 아이콘형 PNG 에셋
- 플레이 감각: 짧은 압박형 생존 플레이
- 바이럴 장치: 강한 밈 톤의 결과 타이틀, 점수, 영양제별 격파 수, 도감 진행도 공유

## 3. 게임 규칙

- 보드 크기: 7x7
- 한 판 등장 영양제: 전체 영양제 풀에서 랜덤 6종
- 매치 규칙: 가로/세로 3개 이상 기본 매치
- 특수 타일: MVP 제외
- 연쇄: 허용
- 시작 시간: 60초
- 종료 조건: 시간이 0이 되면 종료
- 시간 보너스: 매치 성공 시 소폭 회복하되 평균 플레이가 70~90초 안에 끝나도록 제한
- 터치 UX: 보드 조작 중 페이지 스크롤 방지

## 4. 부스트팩

- 모티브: 알고케어 부스트팩
- 충전 기준: 점수 기반
- 충전 속도: 한 판 평균 2~3회
- 사용 방식: 버튼 탭 시 현재 보드에서 가장 많이 존재하는 영양제 1종을 자동 타깃
- 효과: 자동 타깃 영양제를 전부 격파
- 무한 루프 방지: 부스트 격파 점수는 게이지 재충전에 제한적으로만 반영하거나 제외

## 5. 디스펜서 오브제

- 위치: 상단 장식 및 연출 중심
- 형태: 알고케어 로고가 박힌 디스펜서 밑부분을 게임 UI용으로 단순화
- 역할: 새 영양제가 보드로 떨어지는 듯한 시각 모티브 제공
- 부스트 연출: 디스펜서 하단에서 빛/분사 효과 강화

## 6. 영양제 에셋

- 기준 소스: https://www.algocare.ai/products/supplements
- 2026-05-14 재수집 결과: 판매 영양제 14종, 비타민B 없음
- 확인된 14종: 멀티비타민미네랄, 마그네슘, 오메가3, 프로바이오틱스, 칼슘&마그네슘, 비타민D, 밀크씨슬, 홍경천테아닌, 바나바, 보스웰리아, 녹차 카테킨, 멜라토닌, 루테인지아잔틴, 코큐텐
- 수집 대상: 영양제명, 카테고리, 제품 이미지, 알약 이미지, 색상
- 확인된 상위 카테고리: Balance, Focus&Calm, Vital, Special Care
- 생성 방식: 공식 제품 이미지와 공식 `/images/supplements/{code}.png` 알약 이미지를 다운로드해 에셋화
- 스타일: 실제 영양제에 가까운 투명 배경 PNG
- 요구사항: 투명 배경, 모바일 7x7 보드에서 식별 가능한 실루엣과 색 대비
- 데이터 구조: 제품 데이터에 `id`, `name`, `category`, `color`, `image`, `productImage` 매핑

## 7. 도감

- 저장: MVP에서는 localStorage 전용
- 서버 저장: 향후 확장 가능하나 MVP에서는 제외
- 로컬 데이터 마이그레이션: 향후 서버 도입 시에도 하지 않음
- 발견 전: 실루엣만 표시, 이름/카테고리 완전 비공개
- 발견 후: 아이콘, 이름, 카테고리, 누적 격파 수 표시
- 결과 화면 tease: "아직 미발견 영양제가 있습니다" 문구와 실루엣 2~3개 노출, 탭 시 도감 이동

## 8. 결과 화면

- 총점
- 생존 시간
- 강한 밈 톤 결과 타이틀
- 이번 판에서 격파한 영양제 6종과 개수
- 새로 발견한 영양제
- 도감 진행도
- 미발견 영양제 실루엣 tease
- 주요 액션: 다시 하기, 공유하기, 도감 보기

## 9. 공유

- MVP 공유 방식: Web Share API
- 미지원 브라우저: 링크 복사로 대체
- 공유 텍스트 요소: 게임명, 점수, 밈 결과 타이틀, 도감 진행도, 플레이 URL
- 결과 이미지 생성: MVP 이후 확장

## 10. 사운드

- MVP 포함
- 톤: ASMR/클린 사운드
- 매치: 가볍고 맑은 톡/팡
- 콤보: 청량한 글라스 톤
- 부스트: 깨끗한 기계음과 분사음
- 음소거 버튼 제공
- 진동: MVP 제외

## 11. Vercel 배포 설계

- 프레임워크: Next.js App Router
- 배포 대상: Vercel
- 데이터 저장: 클라이언트 localStorage 중심이므로 초기 MVP는 서버 API 없이 정적/클라이언트 중심으로 구성
- 에셋 위치: `public/assets/supplements` 및 `public/assets/sfx` 예정
- 게임 UI: `src/app/page.tsx`에서 진입, 복잡한 게임 로직은 `src/features/game`로 분리 예정
- SEO/공유 메타: `src/app/layout.tsx` metadata에서 관리
- 모바일 대응: `100dvh`, safe area, `touch-action: none`, `overscroll-behavior` 사용

## 12. MVP 범위

- 시작 화면과 짧은 룰 설명
- 7x7 3매치 게임
- 랜덤 6종 영양제 등장
- 60초 생존형 타이머
- 점수/시간/격파 수 계산
- 부스트팩 게이지와 자동 타깃 폭발
- 디스펜서 하단 오브제
- 영양제 PNG 에셋 연동 구조
- localStorage 도감
- 결과 화면
- Web Share API 공유
- 기본 사운드와 음소거

## 13. 제외 범위

- 전체 랭킹
- 서버 저장
- 로컬 데이터 서버 마이그레이션
- 결과 이미지 생성
- 쿠폰/이벤트 보상
- 4개/5개 특수 타일
- 진동 피드백
